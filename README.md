# 📌 Требования к Tasks API (составлены аналитиком)

## 🎯 Цель
Спроектировать API и архитектуру сервиса для управления задачами с возможностью:

- хранения задач в БД или в памяти (для локальной разработки/тестирования)
- создания, обновления, поиска и удаления задач
- сортировки по приоритету и дате создания
- получения статистики по задачам

---

## ✅ Доменные требования

### 🧩 Модель `Task` должна содержать:
| Поле | Тип | Описание |
|---|---|---|
| `id` | `Long` | Уникальный идентификатор (Primary Key) |
| `title` | `String` | Заголовок задачи *(обязательное, не пустое)* |
| `description` | `String` | Описание задачи *(опционально, до 1000 символов)* |
| `status` | `Enum (NEW, IN_PROGRESS, DONE)` | Статус задачи *(обязательное)* |
| `priority` | `Integer (1–5)` | Приоритет задачи *(5 = самый высокий)* |
| `createdAt` | `LocalDateTime` | Дата и время создания *(заполняется автоматически)* |
